# 👋 Hello, I'm Mathilde

I'm French, so my name is pronounced Ma-thild, not Mathilda. You can also call me Matty.  
I'm a software engineer based in London, specialised in iOS development but very curious about programming and systems in general. I spent some time as an Engineering Manager as well. I love coaching people, bringing psychological safety to create a culture of feedback within teams.  
Outside of work, I enjoy long walks outside of the city with my dog, baking and reading. I believe these times allow me to manage busy and stressful London life better, build creativity and see technical problems from a different angle when I'm stuck.

### Thalia

[Website](https://thalia.ing/) / [App Store](https://apps.apple.com/us/app/thalia-wishlists-gifts/id6765488236) / [Play Store](https://play.google.com/store/apps/details?id=com.alphalyrae.thalia)
